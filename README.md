## How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd Python-Basics
```

3. Run a Python file:

```bash
python3 main.py
```

You can replace `main.py` with any other Python filename.
